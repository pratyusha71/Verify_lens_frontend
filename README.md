# 🔍 Verify Lens – Digital Content Authenticity Analysis Platform

### Verify Before You Trust!

Verify Lens is a web-based platform designed to help users assess the authenticity and credibility of digital content. It aims to promote digital awareness by providing preliminary image analysis and helping users identify potential warning signs in digital media.

## 🌐 Live Demo

**Website:** https://verify-lens-frontend.vercel.app/

## ✨ Key Features

- **Image Verification:** Upload images for preliminary authenticity analysis.
- **Metadata Analysis:** Examine image properties and available EXIF metadata.
- **Risk Assessment:** Generate a preliminary risk score based on the analysis.
- **Analysis Report:** Display image format, dimensions, metadata information and assessment results.
- **User-Friendly Interface:** Simple and accessible web interface.
- **Digital Awareness:** Encourage users to verify digital content before trusting or sharing it.

## 🚀 Getting Started

### Prerequisites
- Node.js
- npm
- Python

### Frontend Setup

1. Clone the repository:

   `git clone https://github.com/pratyusha71/Verify_lens_frontend.git`

2. Navigate to the project folder:

   `cd Verify_lens_frontend`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

### Backend Setup

1. Clone the backend repository:

   `git clone https://github.com/pratyusha71/Verify_lens_Backend.git`

2. Navigate to the backend folder:

   `cd Verify_lens_Backend`

3. Install dependencies:

   `pip install -r requirements.txt`

4. Start the Flask server using the instructions in the backend repository.

## 🎯 Project Objective

The main objective of Verify Lens is to encourage responsible digital content consumption by providing users with preliminary information about images and their available metadata.

## ⚠️ Disclaimer

Verify Lens provides preliminary, metadata-based image assessment. Missing or unusual metadata does not conclusively prove that an image is fake, manipulated or AI-generated. The results should not be treated as forensic verification.
